## 사용법

```bash
dotweave skill install [--dry-run] [--force] <directory>
```

코딩 에이전트가 명령, 플래그, 동기화 방향을 추측하지 않고 Dotweave를 정확하게 다룰 수 있도록 지침을 넘겨줘요.

## skill install

| 인자 | 타입과 기본값 | 역할 |
| --- | --- | --- |
| `directory` | `string`, 필수 | 설치할 skills 루트 디렉터리예요. |

| 플래그 | 타입과 기본값 | 역할 |
| --- | --- | --- |
| `--dry-run` | boolean, `false` | 파일을 쓰지 않고 설치 대상만 알려줘요. `--no-dry-run`도 받아요. |
| `--force` | boolean, `false` | 이미 있는 dotweave skill을 덮어써요. `--no-force`도 받아요. |

```bash
dotweave skill install ~/.claude/skills
```

```
✔ Installed dotweave skill
  target: /home/you/.claude/skills/dotweave/SKILL.md
```

## 동작

`skill install`은 바이너리에 내장된 skill을 `<directory>/dotweave/SKILL.md` 파일 하나로 써요. 넘긴 루트 아래에 `dotweave` 하위 디렉터리를 만들어요.

넘기는 `<directory>`는 이미 존재하는 디렉터리여야 해요. `skill install`이 skills 루트 자체를 만들어 주지는 않아요.

보고하는 동작은 `Installed dotweave skill`, `Overwrote dotweave skill`, `Would install dotweave skill`, `Would overwrite dotweave skill` 중 하나이고, 그 뒤에 대상 파일을 알려주는 `target: <path>` 줄이 이어져요. `Would`로 시작하는 두 가지는 아무것도 쓰지 않는 `--dry-run`에서 나와요.

이 명령은 git도 sync 디렉터리도 필요하지 않은 유일한 명령이라 `dotweave init` 전에 실행할 수 있어요.

## 오류

`skill install`은 넘긴 경로가 없거나 디렉터리가 아니면 `Skills root must be a directory.`로 실패하고, `<directory>/dotweave/SKILL.md`가 이미 있으면 `Dotweave skill already exists.`로 실패해요. 두 번째 메시지는 파일을 덮어쓰는 `--force`를 힌트로 알려줘요. 두 코드와 해결 방법은 [오류 메시지](/ko/config/errors/)의 skills 절에서 확인하세요.
