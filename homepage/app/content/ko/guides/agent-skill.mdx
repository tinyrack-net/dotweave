이 가이드를 끝내면 코딩 에이전트가 `dotweave` 스킬을 갖게 돼요. 이 스킬에는 `push`와 `pull`이 데이터를 어느 방향으로 옮기는지, 언제 `dotweave status`를 먼저 확인해야 하는지, 시크릿을 어떻게 다뤄야 하는지가 적혀 있어요. 스킬은 dotweave 바이너리에 포함된 Markdown 파일 하나이고, `dotweave skill install`이 지정한 스킬 디렉터리로 복사해요. 디스크의 디렉터리에서 스킬을 읽는 코딩 에이전트가 필요하고, 그 디렉터리는 명령을 실행하기 전에 이미 있어야 해요.

## 1. 스킬 디렉터리 확인

`dotweave skill install`에는 쓸 파일이 아니라 스킬 루트 디렉터리를 넘겨요. 항상 `<directory>/dotweave/SKILL.md` 파일 하나만 써요.

루트는 이미 존재하는 디렉터리여야 해요. dotweave는 그 안에 `dotweave` 하위 디렉터리는 만들지만 루트 자체는 만들지 않아서, 경로가 없으면 `Skills root must be a directory.`로 실패해요. 에이전트 문서에서 스킬을 읽는 위치를 확인하고, 아직 없으면 그 디렉터리를 먼저 만드세요.

```bash
mkdir -p ~/.claude/skills
```

## 2. 설치 미리보기

`--dry-run`은 대상 경로를 계산해서 알려 주기만 하고 아무것도 쓰지 않아요.

```bash
dotweave skill install --dry-run ~/.claude/skills
```

```
~ Would install dotweave skill
  target: /home/you/.claude/skills/dotweave/SKILL.md
```

이미 스킬이 설치되어 있으면 `--dry-run`만으로도 `Dotweave skill already exists.`로 실패해요. 존재 확인이 dry run보다 먼저 실행되기 때문이에요. 덮어쓰기를 미리 보려면 `--force`를 함께 넘기세요. 그러면 `Would overwrite dotweave skill`로 보고해요.

## 3. 스킬 설치

`--dry-run`을 빼면 파일을 써요.

```bash
dotweave skill install ~/.claude/skills
```

```
✔ Installed dotweave skill
  target: /home/you/.claude/skills/dotweave/SKILL.md
```

이미 있는 스킬 위에 다시 실행하면 `--force` 없이는 실패해요. `--force`를 넘기면 파일을 덮어쓰고 `Overwrote dotweave skill`로 보고해요. dotweave를 업그레이드한 뒤에는 `--force`로 다시 설치해서, 에이전트가 지금 쓰는 바이너리에 담긴 스킬을 읽게 하세요.

<TRAlert.Root variant="neutral">
`dotweave skill install`은 git도, 초기화된 sync 디렉터리도 필요 없는 유일한 dotweave 명령이에요. `dotweave init`을 실행하기 전에도 스킬을 설치할 수 있어요.
</TRAlert.Root>

## 결과 확인

명령이 알려 준 위치에 파일이 생겼는지 확인하세요.

```bash
cat ~/.claude/skills/dotweave/SKILL.md
```

그다음 에이전트에게 사용할 수 있는 스킬 목록을 물어보세요. 목록에 `dotweave`가 보여야 해요. 보이지 않으면 넘긴 스킬 루트가 그 에이전트가 읽는 디렉터리가 아니에요.

플래그 전체 목록은 [`dotweave skill`](/ko/reference/skill/)에서 확인하고, 아직 바이너리가 없다면 [설치 안내](/ko/install/)를 따라 하세요.
