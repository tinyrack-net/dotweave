`dotweave` CLI를 설치하고 git을 찾을 수 있는지 확인해요. dotweave는 컴파일된 네이티브 바이너리로 배포되기 때문에 함께 설치할 런타임이 없어요. `PATH`에 git이 있어야 해요.

## 2. git 실행 파일 확인

dotweave는 git을 전송 계층으로 쓰지만 git을 함께 담고 있지는 않아요. `dotweave skill install`을 빼면 모든 명령이 `PATH`의 `git`을 필요로 해요.

```bash
git --version
```

실패하면 git을 설치하고 셸을 새로 여세요. git이 없으면 dotweave는 `Git is not installed or not on PATH.`라고 알려 줘요.

`age`는 따로 설치하지 않아도 돼요. 시크릿 파일에 쓰는 암호화는 CLI에 내장되어 있어요.

## 결과 확인

상태 점검을 실행하세요. sync 디렉터리를 초기화하기 전에는 종료 코드가 0이 아니고 `git` 실패를 보고하는데, 처음 설정하기 전에는 정상이에요.

```bash
dotweave doctor
```

`dotweave init`을 실행한 뒤에는 같은 명령이 모든 체크를 통과했다고 알려 줘요.

```
· Running checks...
✔ Doctor passed (6 ok · 0 warnings · 0 failures)
```

<TRAlert.Root variant="info">
dotweave는 데이터를 Windows에서는 `%APPDATA%\dotweave`에, 그 밖의 플랫폼에서는 `$XDG_CONFIG_HOME/dotweave`(보통 `~/.config/dotweave`)에 저장해요. `dotweave init`을 실행하기 전에는 아무것도 쓰지 않아요.
</TRAlert.Root>

sync 디렉터리를 만들려면 [첫 동기화 설정](/ko/getting-started/)으로 넘어가고, 탭 자동완성을 먼저 켜고 싶다면 [셸 자동완성 켜기](/ko/guides/shell-autocomplete/)를 확인하세요.
