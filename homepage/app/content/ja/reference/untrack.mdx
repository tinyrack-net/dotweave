## 使い方

```bash
dotweave untrack <target>
```

`manifest.jsonc` から項目を 1 件消し、その項目が同期ディレクトリに書き込んだ内容を片付けます。

## 引数

| 引数 | 型と既定値 | 用途 |
| --- | --- | --- |
| `target` | `string`、必須 | トラッキングを停止するローカルパス（cwd 相対を含む）またはリポジトリパスです。 |

## 動作

`untrack` は該当項目を除いた manifest を書き込み、続いてその項目が置かれていたすべてのプロファイルディレクトリから plain、シークレット、シンボリックリンクの artifact を削除し、空になった親ディレクトリを整理します。このコマンドの `--help` は設定の更新だけを行うと書いていますが、これは誤りです。コマンドが戻った時点で artifact はすでに削除されています。

ホームディレクトリ配下のローカルファイルには触れません。設定ファイルはそのまま残り、同期ディレクトリ内の複製だけが消えます。

ローカルパスを渡すと、主となるトラッキング項目を削除します。トラッキング中のディレクトリ内のリポジトリ相対の子パスを渡すと、そのネストしたオーバーライドだけを削除し、親の項目はトラッキングされたまま残ります。

複数の項目に一致する対象は、推測せずに失敗します。その場合は完全なローカルパスを渡して 1 つを指定してください。

```bash
dotweave untrack ~/.gitconfig
```

```
✔ Stopped tracking .gitconfig
  plain: 1
  secret: 0
```

2 つの数値は、削除された plain artifact とシークレット artifact の件数です。

<TRAlert.Root variant="warning">
`untrack` は対象項目のリポジトリ artifact を、すべてのプロファイルで即座に削除します。ホームディレクトリ配下のローカルファイルは残りますが、同期ディレクトリ内の複製は取り除かれます。他のデバイスがファイルを復元しないよう、この削除をコミットしてください。
</TRAlert.Root>

## エラー

対象が空の場合は `Target path is required.`、一致する項目がない場合は `No tracked sync entry matches: <target>` を返します。どちらもエラーコードとヒントを持ちません。対象が曖昧な場合は `Multiple tracked sync entries match: <target>` と、明示的なローカルパスを使うようにというヒントを返します。各メッセージと対処は[エラーメッセージ](/ja/config/errors/)のトラッキング対象の節を参照してください。

## 関連コマンド

項目を作成するコマンドは [dotweave track](/ja/reference/track/)、リポジトリに何を入れるかの判断は[ファイルとディレクトリのトラッキング](/ja/guides/tracking-files/)を参照してください。
