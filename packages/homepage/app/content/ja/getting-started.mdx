## 新規セットアップ

dotweaveを初めて使う場合は、以下の手順で新しいsyncディレクトリを作成します。

<Steps.Root>
<Steps.Item>

**初期化**

シークレット暗号化用のageキーを含む新しいsyncディレクトリを作成します。

```bash
dotweave init
```

これにより、dotweaveのアプリデータディレクトリにGitリポジトリとageのidentityが設定されます。

</Steps.Item>
<Steps.Item>

**ファイルをトラッキング**

同期したいファイルをdotweaveに登録します。例えば：

```bash
dotweave track ~/.zshrc
dotweave track ~/.config/starship.toml
dotweave track ~/.config/nvim
```

SSHキーなどの機密ファイルにはsecretモードを使います：

```bash
dotweave track --mode secret ~/.ssh/config
```

</Steps.Item>
<Steps.Item>

**syncディレクトリにpush**

トラッキング中のファイルをsyncディレクトリにコピーします：

```bash
dotweave push
```

</Steps.Item>
<Steps.Item>

**Gitでcommit & push**

syncディレクトリを開いてリモートにpushします：

```bash
dotweave cd
git add -A && git commit -m "Initial sync"
git remote add origin <your-repo-url>
git push -u origin main
```

</Steps.Item>
</Steps.Root>

<Callout variant="tip">
  セットアップが完了したら、[ディレクトリ構造](/ja/guides/directory-structure/)ガイドで、dotweaveが設定ファイルと同期データをどこに保存するかを確認してみてください。
</Callout>

## 既存のsyncディレクトリに接続する

新しいマシンで、既存のsyncディレクトリをcloneします：

<Steps.Root>
<Steps.Item>

**cloneして初期化**

```bash
dotweave init <your-repo-url>
```

リポジトリがdotweaveのアプリデータディレクトリ内の`repository/`にcloneされます。既存のsyncリポジトリに接続する場合は、シークレットファイルの復号に使ったageプライベートキーを指定してください：

```bash
dotweave init <your-repo-url> --key-file ~/dotweave.agekey
```

</Steps.Item>
<Steps.Item>

**ファイルをpull**

トラッキング中のすべてのファイルをローカルパスに復元します：

```bash
dotweave pull
```

</Steps.Item>
</Steps.Root>

<Callout variant="note">
  syncディレクトリに暗号化されたシークレットが含まれている場合、すべてのマシンで同じageプライベートキーが必要です。詳しくは[シークレットファイルの同期](/ja/guides/syncing-secrets/)をご覧ください。
</Callout>
