gitベースのsyncディレクトリを初期化します。

dotweaveのアプリデータディレクトリ配下にdotweaveリポジトリを新規作成、または既存のリポジトリに接続し、以降の `pull` や `push` で使用するsync設定を保存します。リポジトリ引数を省略した場合、syncディレクトリ内にローカルgitリポジトリが作成されます。

## Usage

```bash
dotweave init [repository]
```

## Arguments

| Argument       | Description                                              |
| -------------- | -------------------------------------------------------- |
| `[repository]` | cloneするリモートURLまたはローカルgitリポジトリのパスです。省略時はローカルリポジトリが新規作成されます。 |

## Flags

| Flag                        | Description                                                    |
| --------------------------- | -------------------------------------------------------------- |
| `--key-file <path>`         | ファイルからageの秘密鍵を読み込みます。             |
| `--force`                   | 既存のローカルsyncリポジトリ、identity、settingsを置き換えて初期化します。 |

## Examples

新しいローカルsyncディレクトリを作成する:

```bash
dotweave init
```

リモートリポジトリをsyncディレクトリとしてcloneする:

```bash
dotweave init https://github.com/user/dotfiles.git
```

既存のageの秘密鍵を指定して初期化する:

```bash
dotweave init --key-file ~/dotweave.agekey
```

<Callout variant="tip">
別のマシンで使用しているage identityがある場合は、`--key-file`で指定するか、既存リポジトリを取り込むときの対話プロンプトに入力すると、secretファイルを復号できます。
</Callout>
