## 처음 시작하기

dotweave를 처음 사용한다면, 아래 단계를 따라 새로운 sync 디렉터리를 만들어 보세요.

<TRSteps.Root>
<TRSteps.Item>

**초기화**

새로운 sync 디렉터리를 만들고 시크릿 암호화를 위한 age 키를 생성해요.

```bash
dotweave init
```

dotweave 앱 데이터 디렉터리에 Git 저장소와 age identity가 설정돼요.

</TRSteps.Item>
<TRSteps.Item>

**파일 추적**

동기화할 파일을 dotweave에 알려주세요. 예를 들면:

```bash
dotweave track ~/.zshrc
dotweave track ~/.config/starship.toml
dotweave track ~/.config/nvim
```

SSH 키 같은 민감한 파일은 secret 모드를 사용하세요:

```bash
dotweave track --mode secret ~/.ssh/config
```

</TRSteps.Item>
<TRSteps.Item>

**sync 디렉터리로 push**

추적 중인 파일을 sync 디렉터리에 복사해요:

```bash
dotweave push
```

</TRSteps.Item>
<TRSteps.Item>

**Git으로 commit & push**

sync 디렉터리를 열고 리모트에 push하세요:

```bash
dotweave cd
git add -A && git commit -m "Initial sync"
git remote add origin <your-repo-url>
git push -u origin main
```

</TRSteps.Item>
</TRSteps.Root>

<TRCallout variant="tip">
  설정을 마쳤다면, [디렉터리 구조](/ko/guides/directory-structure/) 가이드에서 dotweave가 config과 동기화된 파일을 어디에 저장하는지 확인해 보세요.
</TRCallout>

## 기존 sync 디렉터리 연결하기

새 기기에서는 기존 sync 디렉터리를 clone해서 연결할 수 있어요:

<TRSteps.Root>
<TRSteps.Item>

**Clone & 초기화**

```bash
dotweave init <your-repo-url> --key-file ~/dotweave.agekey
```

저장소를 dotweave 앱 데이터 디렉터리의 `repository/` 아래로 clone해요. 기존 sync 저장소에 연결할 때는 시크릿 파일 복호화에 사용했던 age 비밀 키를 반드시 제공해야 해요. 키를 직접 입력하는 대신 붙여넣기 프롬프트를 사용할 수도 있어요:

```bash
dotweave init <your-repo-url>
```

</TRSteps.Item>
<TRSteps.Item>

**파일 pull**

추적 중인 모든 파일을 로컬 경로로 복원해요:

```bash
dotweave pull
```

</TRSteps.Item>
</TRSteps.Root>

<TRCallout variant="note">
  sync 디렉터리에 암호화된 시크릿이 있다면, 모든 기기에 같은 age 비밀 키가 있어야 해요. 자세한 내용은 [시크릿 파일 동기화](/ko/guides/syncing-secrets/)를 참고하세요.
</TRCallout>
