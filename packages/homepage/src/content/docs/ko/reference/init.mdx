git 기반 sync 디렉터리를 초기화해요.

dotweave 앱 데이터 디렉터리 아래에 로컬 dotweave 저장소를 만들거나 연결한 뒤, 이후 `pull`과 `push`에서 사용할 sync 설정을 저장해요. repository 인자를 생략하면 sync 디렉터리에 로컬 git 저장소를 새로 만들어요.

## Usage

```bash
dotweave init [repository]
```

## Arguments

| Argument       | Description                                              |
| -------------- | -------------------------------------------------------- |
| `[repository]` | clone할 원격 URL 또는 로컬 git 저장소 경로예요. 생략하면 새 로컬 저장소를 만들어요. |

## Flags

| Flag                        | Description                                                    |
| --------------------------- | -------------------------------------------------------------- |
| `--key-file <path>`         | 파일에서 age 개인 키를 읽어요.             |
| `--force`                   | 기존 로컬 sync 저장소, identity, settings를 교체하고 초기화해요. |

## Examples

새 로컬 sync 디렉터리를 초기화해요:

```bash
dotweave init
```

원격 저장소를 clone해서 sync 디렉터리로 사용해요:

```bash
dotweave init https://github.com/user/dotfiles.git
```

기존 age secret key로 초기화해요:

```bash
dotweave init --key-file ~/dotweave.agekey
```

<Aside type="tip">
다른 머신에서 쓰던 age identity가 있다면 `--key-file`로 전달하거나, 기존 저장소를 가져올 때 나오는 대화형 프롬프트에 입력하세요. secret 파일을 복호화할 수 있어요.
</Aside>
